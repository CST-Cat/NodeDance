# S04：Docker全量发现、事件同步与状态模型

**前置阶段：** S03。  
**估算：** 9–13 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

从Docker Engine全量列举所有来源（含停止容器）；使用Engine事件驱动更新并每60秒全量校验；初次连接、重连和Engine恢复执行完整快照，只有成功完整快照才可删除缺失资产；采集状态、健康、时间、网络、IP、挂载、配置端口和实际端口；处理重复/乱序/迟到事件、删除、重命名和事件历史缺口；Docker不可用时保留最后状态并标过期。外部创建、改名、停止和删除应自然同步。EXPOSE不能伪装宿主机发布；Running不能伪装应用Healthy；半份快照不能清空资产；状态与真实Engine不一致必须驳回。正常变化同步P95目标≤5秒。
