# S03：VPS指标采集与实时展示

**前置阶段：** S02。  
**估算：** 5–7 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

采集系统信息、架构、CPU、内存、磁盘、网卡和运行时间。CPU、内存、网络默认5秒，磁盘30秒；用计数差分计算网络速率；单项权限问题不能影响其他指标；Docker查询与采集/心跳隔离；Core无浏览器时仍收数据。公式和单位需与独立 `/proc`、文件系统观测对照。未知不能显示成0，计数器重置不能产生负速率，虚拟接口不能重复汇总，Docker卡死不能使Agent失联；正常网络指标更新P95目标不超过8秒。
