### 候选实现和本地验证

已经建立持久化 Agent 状态机、Inspect 实时计划、Docker 重建/恢复/明确清理、Core 任务桥和计划 API、响应式 Web 向导，以及 Engine 28/29 的隔离 DIND 工作流。默认绝不删除挂载卷；容器可写层快照只保护未挂载的容器层，不作为卷或 bind mount 备份。清理旧回滚容器前，先验证替换容器、任务 owner label、快照精确 ID、快照 owner/task label 和旧回滚容器名称/状态；任何不匹配会保留回滚容器。

## 实施范围、样例和阶段门槛

读取Inspect并制定保留清单；检查镜像、挂载、网络、可写层与剩余空间；必要时先快照可写层；保留旧容器并释放名字/网络后创建新实例；恢复配置、卷、网络和展示偏好；健康、端口与实际运行检查成功后完成；失败恢复旧实例；提供显式回滚资源清理，默认不删卷。容器快照不包含挂载卷内容，界面不得将其描述为业务数据备份。高风险配置不能可靠保留时，必须破坏旧容器前拒绝。先删旧容器、漏匿名卷/网络、数据卷自动删除或失败冲突均驳回。
