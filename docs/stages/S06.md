# S06：融合首页、偏好、详情与历史监控

**前置阶段：** S05。  
**估算：** 10–14 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

服务器与Docker融合卡片、默认4个主要容器、监控/管理视图、分组/搜索/排序/字段、别名/图标/备注/顺序/服务入口；节点和容器详情；分钟与小时历史聚合、缺失样本、加权平均、保留和清理。分钟数据默认30天，小时默认一年；别名只改NodeDance偏好，不调用Docker Rename；偏好绑定经验证的稳定身份；失联数据明显过期；服务入口必须由管理员配置。桌面/平板/手机Web响应式视口均需可读操作。身份继承错误、缺口补零、别名修改真实名称、重启后排序丢失、手机关键操作不可达均驳回。
