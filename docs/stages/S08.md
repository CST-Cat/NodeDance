# S08：Docker镜像管理

**前置阶段：** S07。  
**估算：** 3–5 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

列表、搜索、标签和容器引用；真实拉取、进度、取消与验证；一次性Registry认证；检查引用并默认禁止删除使用中的镜像；接入持久任务、审计和断线待确认。假进度、失败仍报成功、默认强删引用镜像、明文保存凭据或绕过任务/审计均驳回。

镜像拉取字节进度只从Docker JSON流的`progressDetail.current`和`progressDetail.total`读取；`status`或格式化的`progress`字符串不算字节。按layer ID汇总并忽略重复/迟到的较小计数；总量未知时不显示字节百分比；完成字节不得超过总量。Agent限频写任务日志时，拉取结束前必须持久化最后观测值。GitHub Actions的owner-marked慢速Registry用例要求取消前和取消后任务日志都保有正数且合法的真实字节进度。
