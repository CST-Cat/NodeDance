# S02：Agent注册、身份与通信可靠性

**前置阶段：** S01。  
**估算：** 7–10 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

Core 创建绑定节点、默认10分钟一次性的注册凭据；注册后分配独立设备身份，Core 仅保存长期凭据验证摘要；Agent 安全持久化凭据；实现协议版本、能力声明、5秒心跳、最多30秒失联判断、退避重连、连接代际、凭据轮换和撤销；提供注册及 systemd 安装命令。三节点身份不混用，重启后稳定复连，断网/重启后新代际同步，Agent 不新增管理监听端口。共享长期Token、日志泄露凭据、默认跳过TLS、旧代消息覆盖新状态、浏览器离线导致采集停止均驳回。
