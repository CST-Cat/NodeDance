# S01：私有Core、管理员鉴权和审计基础

**前置阶段：** S00。  
**估算：** 7–10 个开发日。  
**当前状态：** 以 [最新机器报告](../../reports/stages/S01.json) 的新鲜 `run_id`、`mode`、`status` 和逐项 `runs` 为准。源码实现不等于验收完成；本阶段须在一次完整真实运行中通过十二项原始用例才可标记 `PASS`。既有 PASS 报告按旧三轮规则产生，作为历史证据保留，未按新规则重跑。

## 实施范围、样例和阶段门槛

实现 SQLite 初始化、WAL、迁移和优雅退出；一次性本机初始化凭据；单管理员 Argon2id 随机盐密码；服务端 Session、安全 Cookie、CSRF、限流、可信代理及 WebSocket 来源检查；退出、改密、会话管理；登录页外观；敏感审计脱敏。未登录请求任意管理资源必须 `401`，没有私有数据；改密撤销旧 Session，已建立 WebSocket 也在 30 秒内失效。无凭据初始化、固定盐、明文密码、仅前端拦截、撤销后 WebSocket 永久存活、跨站请求通过或数据库迁移破坏原数据均驳回。

## 配置与部署

默认数据目录为 `$XDG_DATA_HOME/nodedance`，未设置时为 `~/.local/share/nodedance`。目录选择顺序为 `--data-dir`、`NODEDANCE_DATA_DIR`、配置文件 `data_dir`、默认值。默认配置路径为 `$XDG_CONFIG_HOME/nodedance/config.json`，未设置时为 `~/.config/nodedance/config.json`；CLI 参数优先于环境变量，环境变量优先于 JSON 配置。

本机 HTTP 浏览器开发必须显式使用 `--dev`，且监听地址必须是回环地址。生产 Session 与 CSRF Cookie 始终设置 `Secure`；生产必须通过 HTTPS 反向代理访问，并设置 `--public-origin https://面板域名`。只有 `--trusted-proxies`/`trusted_proxies` 中明确列出的代理 IP/CIDR 才能提供可信的 `X-Forwarded-For` 地址；默认不信任 XFF/XFP。WebSocket Origin 必须等于 `public_origin` 或当前同源地址。浏览器和原生 API 写请求均需 Origin 及 CSRF 双提交：从 `/api/v1/auth/csrf` 获取挑战，Cookie 与 `X-CSRF-Token` 必须相等；已登录请求还必须匹配服务端 Session 绑定的摘要。

生产空闲 Session 默认 12 小时；限流默认每 IP 五次失败后冷却 15 分钟；WebSocket 最多每 10 秒检查 Session，检查间隔始终不得超过 30 秒。仅 `--dev` 可调整 `session_idle_timeout`、`login_max_attempts`、`login_lockout_duration` 和 `websocket_check_interval` 来测试短时间过期或恢复。首次启动的 `setup-credential.txt` 位于数据目录，权限为 `0600`，CLI 只打印文件路径；公开 setup status 只给初始化状态和通用提示。初始化成功后文件与数据库内一次性摘要都会消费。

一次性图片只接受有大小、尺寸和像素上限的 PNG/JPEG/GIF 输入，Core 解码后重新编码为 PNG；SVG/HTML 不公开。匿名图片 API 只提供当前登录页外观引用的头像/背景固定路径。展示名称在 Vue 文本节点中渲染，不作为 HTML 插入。

示例：

```sh
.build/nodedance serve --listen 127.0.0.1:8180 \
  --public-origin https://panel.example.test \
  --trusted-proxies 127.0.0.1
```
