# S15：告警、恢复及通知

**前置阶段：** S14。  
**估算：** 6–9 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

实现节点、CPU、内存、磁盘、Docker、容器和探测告警；支持阈值、持续时间、期望运行态、去重、冷却、恢复、确认、静默和维护窗口；抑制失联节点的重复下级告警；实现站内、Webhook、SMTP通知；投递结果持久化、有界重试、凭据加密、测试发送及历史。默认资源告警可配置为90%持续5分钟。每类规则需实测触发和恢复；无限重复、未发送报成功、凭据泄漏或重启丢告警均驳回。
