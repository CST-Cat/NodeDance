## 候选实现

候选实现由共享 Compose 编辑协议、Agent 本机事务管理器、Core 编辑 API 与持久操作账本、以及响应式 Vue 编辑器组成。Agent 在原项目目录按原文件顺序、env 文件和 profile 执行 `docker compose config`；预览临时文件放在各源文件旁边，并保持原 `--project-directory`，以保留相对挂载解析。预览只返回差异、受影响服务、影响说明和脱敏后的解析配置。

Apply 会重新校验每个上下文文件的 SHA-256 版本，先写入权限为 `0600` 的源文件备份和事务日志，再保留旧容器镜像 ID 的本地标签，原子替换源文件，并只对受影响服务执行 `up --no-deps --build`。回滚使用固定镜像覆盖配置并显式传入 `--no-build`，避免当前 build context 改写已固定的旧镜像。之后根据 Engine 实际容器状态、健康检查和端口绑定确认结果。失败时恢复原文件与受影响服务；数据卷不属于配置回滚范围。进程重启后 Agent 从本地事务日志恢复；Core 的去重键和状态事件不保存源文件内容，断线结果未经确认时保持 `unknown`。

返回浏览器的 resolved config 会在全树递归遮罩 environment、build args 等敏感字段名（password、token、secret、key、credential、auth 等大小写及常见驼峰/分隔写法）。针对 build args、嵌套凭据字段及 `KEY=value` 列表有回归测试；测试数据只使用虚构标记，不在测试失败消息中打印 resolved config。

生产 SQLite 迁移顺序：Compose 项目与操作表为 **v5**，S11 编辑账本与事件表为 **v6**。后续合并若还需补入 S06 数据表，只能新增 v7 或更高版本，不得重排或回填既有迁移版本。
