# S13：Tailscale发现与SSH辅助部署

**前置阶段：** S12。  
**估算：** 7–10 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

读取本机 `tailscale status --json` 的可见节点；区分候选、已纳管和不适用系统；提供手动安装，或使用一次性SSH凭据启动有审计部署任务；验证主机指纹、权限、架构和发布签名；确认systemd Agent注册上线；清理失败临时文件；主路径不可用时只按显式授权启用可信HTTPS备用地址。发现节点本身不代表获得部署许可。自动发现即自动安装、忽略SSH主机指纹、长期明文凭据、默认切备用通道或再造日常SSH Docker后端均驳回。
