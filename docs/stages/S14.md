# S14：HTTP/HTTPS/TCP服务探测

**前置阶段：** S13。  
**估算：** 3–5 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

由目标节点Agent发起HTTP/HTTPS/TCP探测；默认间隔30秒、超时3秒；可配目标和HTTP期望状态；默认连续3次失败异常、连续2次成功恢复；节点失联时显示未知；并发有界。回环地址从目标节点解释，TLS证书验证默认启用。浏览器代探测、忽略TLS、单次失败告警、慢探测堵塞心跳或节点离线显示探测正常均驳回。
