# S10：文件浏览、传输和文本编辑

**前置阶段：** S09。  
**估算：** 7–10 个开发日。  
**当前状态：** `NOT_READY`。

## 实施范围、样例和阶段门槛

浏览目录、属性、权限；安全创建、重命名、删除；流式上传下载（单文件默认上限1GiB）；先临时写入、校验、原子提交；编辑使用版本检查、冲突检测、备份和原子替换；校验路径根、符号链接、权限、所有者；Session撤销停止未提交传输。100MiB和1GiB文件哈希一致、增量内存差≤64MiB；失败不能损坏原文件。路径越界、失败覆盖、静默丢权限、静默覆盖SSH并行修改均驳回。
