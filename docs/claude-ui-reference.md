# Supplementary UI reference / 补充界面参考

现有差异预览、复制反馈和动效可保留已接入的实现；共享操作、权限、任务及恢复流程不由视觉参考定义。新增或替换控件须从 shadcn CLI 安装到本地并复用已有 UIArc 组件，不复制参考中的另一套控件或主题。复用第三方代码或资源时保留适用许可和归属，产品已分发通知见 `web/public/licenses/ui-notices.txt`。

This page states the reference boundary, not a claim of a new Figma or Storybook inspection. Installed sources and the current repository rules determine implementation details. See [UIArc integration](uiarc.md).
