## 最终修复与验证

共享验收脚本 [acceptance-s00.py](../../scripts/acceptance-s00.py) 的 S00-07 日志路径现已改为：

```python
log = attempt_dir() / "case-07-server.log"
```

这样每轮独立产生 `attempt-1/`、`attempt-2/`、`attempt-3/` 中的日志，且落在 CI artifact 上传的 `.artifacts/logs/acceptance/` 路径下。脚本中服务进程的 runtime `HOME` 已移到不上传的 `.artifacts/work-s00/<run>/attempt-*/`；这是因为 S01 Core 会在 HOME 数据目录生成私有数据，不能把它混入 S00 原始日志 artifact。最终 CI 的四个 S00 artifact 都各自包含并满足三个不同 attempt 的 S00-07 日志引用。
