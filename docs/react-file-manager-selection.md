# React file manager / React 文件管理

文件管理主体采用项目已安装的 shadcn／UIArc 组件；列表与网格复用同一套自绘右键菜单，elFinder 仅在隐藏环境中提供命令能力，图标保留用户提供的资源。当前实现和验证说明见 [file-manager.md](file-manager.md)。

- 总览、节点详情和 Compose 目录选择复用同一个 React 文件管理组件。
- 列表、目录树、工具栏、右键菜单、上传、搜索、分页和所有弹窗使用本地安装组件，保留原版样式及键盘行为，只绑定业务数据并安排外部布局。
- 图片编辑保留本地 TOAST UI 无内置 UI 的画布引擎，其参数、工具、撤销重做及保存均由 shadcn 控件呈现。
- Web、CLI、TUI 继续发现同一 Core 操作契约；所有文件执行、权限、路径保护、版本检查和任务语义由现有 Core／root Agent 提供。
- 隐藏的命令层只接收当前文件元数据并把操作交回同一 React 分发入口，不提供独立文件服务或旧 connector API。

- 文本预览和编辑使用用户指定的 CodeMirror 6 专业引擎，支持高亮、行号、搜索替换、折叠、补全和撤销重做；外围按钮继续使用本地安装组件，不增加配置校验。
