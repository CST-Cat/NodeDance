# Language / 语言

Web supports **English** and **简体中文**. The default follows the browser's preferred languages, matching Chinese or English and falling back to English. Personal settings includes a language control beside the background color: Follow browser, Simplified Chinese and English. It applies immediately and saves only in the current browser; no Core account setting changes. Automatic follows browser `languagechange` notifications. Manual choices persist across refresh and override browser preferences. The header has no language control.

Web 支持 **English** 和 **简体中文**，默认按浏览器语言偏好匹配中文或英文，无法匹配时回退英文。个人设置页在背景颜色右侧提供“跟随浏览器／简体中文／English”，即时生效并仅保存于当前浏览器，不修改 Core 账号设置。自动模式跟随浏览器语言变化，手动选择跨刷新保留并优先于浏览器；顶部不显示语言控件。

```sh
nodedance --lang zh-CN help
nodedance operations --lang en
nodedance tui --lang zh-CN --server https://core.example
nodedance-agent enroll --lang zh-CN --server https://core.example --token-stdin
```

The global `--lang en|zh-CN` option takes priority over `NODEDANCE_LANG`, then `LC_ALL`, `LC_MESSAGES` and `LANG`. TUI also supports `l` to switch languages. An Agent subprocess inherits the selected CLI language. English is the fallback. Command names, request fields, enum identifiers, terminal output, downloaded files and machine result data stay unchanged. Known public API errors are localized by the Web UI; unknown host/Docker diagnostics remain verbatim for troubleshooting.

全局 `--lang en|zh-CN` 优先于 `NODEDANCE_LANG`，然后依次是 `LC_ALL`、`LC_MESSAGES`、`LANG`。TUI 还可按 `l` 切换，Agent 子进程继承 CLI 所选语言。默认回退到 English。命令名称、请求字段、枚举标识、终端输出、下载文件和机器结果数据保持原样。Web 翻译已知公共 API 错误，未知主机/Docker 诊断保留原文便于排查。

Web catalogs are in `web/src/locales`; Go presentation messages are in `internal/i18n`. Add both languages together and preserve interpolation slots. `make check` verifies catalog parity, placeholders, nonempty English translations, known message keys, browser-language selection and fallback, command schemas and interactive TUI switching. Message values are rendered as React text, never HTML. Webhook templates such as `{{event}}` are preserved.

Web 语言目录位于 `web/src/locales`，Go 文案位于 `internal/i18n`。新增文案必须同时提供两种语言并保留参数槽位。`make check` 检查目录键与参数一致性、英文完整性、有效键、浏览器语言选择及回退、命令结构和 TUI 交互切换。文案使用 React 文本渲染，不作为 HTML；`{{event}}` 等 webhook 模板保持原样。
